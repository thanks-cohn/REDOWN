## Stage 2: attachment and contextual URLs

Audit: `assetCorsControl → cfSetAssetDomain → configureAssetDomain` attaches a **Worker Custom Domain**, adds R2 CORS, saves `/assets` delivery configuration, and deploys the bucket Worker with explicit public delivery. It does not attach a direct R2 custom domain or merely save text. Feedback and the former hardcoded folder URLs were Debug-only; UI then overwrote background-saved profiles and claimed public serving without any public connection check.

Now Normal Mode explains this public-delivery action and shows progress/results. Attachment reads back the exact hostname + Worker association before saving it; an interrupted/missing read-back reports Unknown. CORS/deployment failures after association report Needs setup, preserved across reload. The background reloads before changing one destination; Settings no longer overwrites its result with an older profile list. A bounded unauthenticated GET checks public Worker health separately; verified **connection** never means an individual file exists. CORS/extension host permissions may prevent that public probe, in which case association remains Attached with explicit unverified DNS/SSL guidance. No additional host permission or Cloudflare authorization scope was introduced.

New `cfPublicAddresses` performs read-only managed `r2.dev`, R2 custom-domain, and exact Worker-domain discovery. It never prepares/deploys/enables storage. New shared `public-addresses.js` renders native collapsed URLs details with Copy/Open controls, accurate configured/pending/disabled/unknown labels, account/bucket identity checks and generation protection. Bucket settings show bases; previews show per-segment encoded full keys (including Unicode, spaces, #, ?, %). Worker `/assets/` addresses retain their contract and are explicitly labeled; no invented `r2.dev` fallback. Restricted/pending/unknown addresses cannot be opened/copied as usable public links. No addresses means no disclosure. Authenticated private blob previews/lightbox remain independent. Existing private “Open original file” remains separate from public URL information.

API schema retrieved 22 October through Cloudflare's OpenAPI search: GET `/accounts/{account_id}/r2/buckets/{bucket_name}/domains/{managed,custom}`, GET/PUT `/accounts/{account_id}/workers/domains`. R2 `enabled`, ownership and SSL are configuration, not external object checks.
