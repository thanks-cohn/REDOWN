## CURRENT, overflow and recovery foundation

Subsequent production code adds `right-click-current.js` and its background bridge.
CURRENT's record changes, provider-scoped JSONL events, scan verification metadata,
dated immutable anchors and generation pointers commit in one IndexedDB transaction.
`storage.local` remains a compatibility mirror, repaired from CURRENT on wake and
before click resolution. Native acknowledgment is separate and cannot acknowledge
a newer generation using an older receipt. Atomic rejection, restart, parallel
writers and 20-edit immutable-anchor tests use fake-indexeddb; they are not Chrome
storage/process-kill proof. Daily/Weekly/Off is exposed in Shelf Settings. No daily
cloud crawl is added. Partial discovery merges directory additions; auth changes
retain historical metadata while projection and save recheck current authority.

`right-click-chooser.*` provides a searchable full projection for omitted native
rows. Its source intent lives in extension session storage for ten minutes, the
sender must be the exact chooser page, and the intent is consumed before transfer.
Its source URL and authorization are never reconstructed from menu labels. Native
and chooser saves share the existing ingest and HEAD verification function.

Shelf Settings exposes encrypted independent file export/import. A user file
picker precedes any filesystem write. PBKDF2-SHA256 (210,000 iterations) and AES-GCM
protect the versioned bundle, with a portable JSONL representation. Verification
requires closing the writer, reading the selected file back, decrypting/validating
it and comparing its content. Download-only fallback explicitly remains unverified.
Restore rejects corruption, invalid identities/schema, credential fields and
nonempty CURRENT; it accepts an empty installation, restores no credentials and
refuses to reuse existing profiles. Reconnection and exact destination review are
required. The older migration-recovery export is also recursively sanitized.
**No independent real user file or live cloud backup was written during this run.**

Stable native IDs: `v3:provider:cloudflare` (default leaf or navigation-only parent),
`:default` (Home save), `:separator` (native separator), `:more` (chooser), `v3:<id>`
(configured destination), `v3:<id>:send` (configured ancestor Save here),
`v3:path:<encoded tuple>` (structural ancestor) and `v3:cloud:<encoded tuple>`
(Depth directory). `redown-go-home` remains a distinct dashboard navigation ID.
The exact primary R2 target is the prepared profile's account, literal bucket
`redown`, empty prefix; Explorer selection is not consulted. No live save receipt
exists. Existing fixtures verify provider key, size, ETag and source metadata.
