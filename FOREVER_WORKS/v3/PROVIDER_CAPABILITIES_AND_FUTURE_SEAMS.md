# Present capabilities and deferred seams

Cloudflare R2 is the only V3 menu destination provider. Account/bucket/prefix identity, preparation, provider transport and result verification remain separate from presentation and native menu projection. These boundaries permit later adapters without implementing speculative providers now.

S3-compatible providers, Google Drive, OneDrive, Dropbox, MEGA, generic browser-byte delivery, durable resumability, premium features and billing are not implemented. Existing dormant/Beta provider code is not advertised as working V3 support. Authentication, object identity, conflict semantics, remote URL ingestion, signed/public links and verified completion must be proved independently for each future provider.
