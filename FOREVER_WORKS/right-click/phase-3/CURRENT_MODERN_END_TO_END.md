Each rendered card/row has a permanent red deletion control; collapsed descendants are hidden, not deleted. CSS can wrap/scroll the folder outline without altering nestedMenu. Chrome native flyouts cannot be styled by these rules. Tests prove selected DOM interactions with mocks, not the preferred appearance in every panel or native routing in the user's profile.
