## Races, registration and click

A dirty profile storage event preserves draft and asks Reload; stale expected will reject. Dirty mode-only event reuses original menu projection in expected, updates mode, preserves edits. Clean event reloads; events while saving/activating are ignored. `beforeunload` warns when dirty. Save locks panel inputs/selects/buttons but native details/summary can still toggle. Cache/discovery freshness is not remote readiness proof.
