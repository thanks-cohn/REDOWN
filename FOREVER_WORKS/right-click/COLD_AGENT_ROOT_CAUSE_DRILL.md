# Cold-agent root-cause drill

[Route](README.md) · [diagnostic tree](CHROME_MENU_PARITY_AND_DIAGNOSTIC_TREE.md) · [reproduction](evidence/phase-2/REPRODUCTION.md)

Recipe only: no independent agent execution or source-independent reconstruction is claimed. Read AGENTS, Phase2 handoff, owner direction and actual result ledger. Verify source revision/hashes before applying anchors. An owner's screenshot is an observation, not permission to inspect credentials or mutate storage/provider resources.

1. Classify screenshot as Legacy config, Modern config, native Chrome menu or Explorer file-grid context menu. Ask what changed and whether Save was acknowledged, without assuming user error.
2. Identify synthetic/redacted stable card/profile ID, exact mode and expected bucket/prefix/name. Compare visible draft, persisted projection and normalized plan independently.
3. Reproduce D1: historical actual selector callback auto-persists; current add/label stays draft until Save. If owner's saved projection already contains edit, stop blaming autosave difference.
4. Reproduce D6: same blank-label files prefix with bucket fallback historically and current plan. Find provisioning/default-prefix/explicit menuLabel source; distinguish inheritance from active Legacy writer. Owner now requires automatic bucket naming without path changes.
5. Reproduce D2: old-only menuTree vs current empty native plan, migration draft and hidden unready child; expand/discover/save. If valid modern model exists, migration hypothesis does not apply. Empty version1 must not resurrect old entries.
6. Reproduce D3: saved state + native callback error/empty menu. Trace signature, queue, storage, parent-first callback, menuUpdated. Then examine actual permitted installed registration evidence; mock behavior does not diagnose a real Chrome error.
7. Trace ID→fresh resolve→prepared same-account bucket/prefix→source reference→Worker/provider→receipt/history. A missing item and an inaccessible source are different first failures.
8. Identify feedback (notification disabled/status overwritten) separately from mutation. Do not blindly replay uncertain writes or repair/deploy as a diagnostic read.
9. Record confirmed source/local behavior, owner report, competing hypothesis, counterexample and minimum missing test. Do not close incident by writing a plausible cause.

Acceptance for a later independent drill: agent given only README/source/evidence can identify the first failed boundary for a specific synthetic complaint, cite exact revision/line/test/output, state negative case and propose a safe scoped follow-up without changing production or cloud state. This has not been independently demonstrated in this run.
