Google Drive

Save supported web files to your Google Drive without saving a permanent copy to your computer.

Keep this tab open during transfer. Public HTTPS files up to 32 MiB are supported. Chrome receives the file bytes; this is a browser-mediated transfer. Closing this tab interrupts it. Redirects, authenticated sites and blob links are not supported.

One file at a time. While a save is running, another right-click save returns here without queuing a second file.
