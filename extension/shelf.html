Getting started

A reliable save starts with authorization

  1. Configure this independent extension’s OAuth clients as described in the repository README.
  2. Choose Sign In on a provider card. Approve the requested upload permissions.
  3. Right-click a downloadable image or link, then choose Save to Google Drive, Save to Dropbox or Save to OneDrive.
  4. Check the result in History. Saved means the provider confirmed the object. For an uncertain result, check your cloud before retrying.

When a save needs attention

GO TO opens the provider website; it does not authorize this extension. Refresh reuses or silently renews extension authorization where supported. Reconnect/Approve addresses missing or revoked permissions.

Private pages, blocked downloads, HTML login pages, empty responses, unsupported schemes and oversized resources are rejected with a reason. Opening a website successfully does not prove upload access. Diagnostics can help identify the stage and reason for a failed save.

Live Chrome right-click behavior and all three providers require independent live acceptance. Local tests alone are not a release certificate.

Small by design

REDOWN Basic

A focused, independent Chrome extension for saving downloadable resources to Google Drive, Dropbox and OneDrive.

Source bytes and necessary file metadata go directly to the chosen provider. Host page and source URLs remain local in History and optional diagnostics; they are not attached to cloud objects.

There is no local server, companion extension or cloud worker requirement. See the repository documentation for versioned API contracts, setup, limits and verification evidence.
