# Google Drive — REDOWN competitor brief

**Category:** first-party cloud storage and Drive for desktop  
**Priority:** P1  
**Status:** Strategy with cited starting points; manually verify product versions and feature availability before implementing claims.

## What the competitor does well
Massive reach, strong collaboration, simple sharing and integration with Google's document ecosystem.

## What we should borrow as product principles
Approachable folder hierarchy, sharing visibility, search and reliable first-party account sign-in.

## Where REDOWN could win
Stay independent of a single provider: right-click one or multiple clouds, replication monitoring, provider-neutral file catalog and recovery.

## Where they can beat us / reality check
Extreme distribution and trust advantage; REDOWN must never pretend to replace Docs or collaboration.

## REDOWN API and cold-agent implications
Provider-neutral object/location identity; Google Drive scope and folder authorization diagnostics; manifest/link/sharing metadata.

## Concrete competitive / QA experiment
Test folder create/upload/rename and 403 permissions with actual authorized token; support Drive and Cloud Storage as distinct products.

## Rules of engagement
Maintain REDOWN's one-click DONE workflow, user-owned execution model where authorized, no false transfer or replica success, no silent destructive cleanup, auditable provider scopes and error handling, accessible simple mode, desktop expansion via shared experience. Competitor strengths are inspiration; do not copy proprietary assets or obscure needed confirmation.
