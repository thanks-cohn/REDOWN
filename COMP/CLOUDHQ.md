# cloudHQ — REDOWN competitor brief

**Category:** hosted cloud sync and browser productivity extension suite  
**Priority:** P1  
**Status:** Strategy with cited starting points; manually verify product versions and feature availability before implementing claims.

## What the competitor does well
Established background cloud workflows and productivity-oriented extensions.

## What we should borrow as product principles
Setup wizards, durable cloud jobs, account health indicators, monitored automation.

## Where REDOWN could win
Single small coherent multi-cloud machine versus a larger suite; low-friction browser capture and readable per-object status.

## Where they can beat us / reality check
High in managed cloud automation; user-owned infrastructure does not automatically match hosted reliability.

## REDOWN API and cold-agent implications
Scheduled agent-independent jobs, webhook notification, retry semantics, backend execution identity and audit.

## Concrete competitive / QA experiment
Browser closed and computer off: verify declared job completion under supported cloud execution; include provider outages.

## Rules of engagement
Maintain REDOWN's one-click DONE workflow, user-owned execution model where authorized, no false transfer or replica success, no silent destructive cleanup, auditable provider scopes and error handling, accessible simple mode, desktop expansion via shared experience. Competitor strengths are inspiration; do not copy proprietary assets or obscure needed confirmation.
