# SaveAnywhere (AMZBoosted) — REDOWN competitor brief

**Category:** free browser right-click multi-cloud saver  
**Priority:** P0  
**Status:** Strategy with cited starting points; manually verify product versions and feature availability before implementing claims.

## What the competitor does well
Browser shelf, provider sign-in, right-click Save to All Connected, auto-rules, queue/history, pleasant micro-animation; claims locally processed transfers.

## What we should borrow as product principles
Frictionless OAuth, meaningful context menu, shelf, routing rules, zero-server ordinary browser upload architecture; small celebration animation.

## Where REDOWN could win
Build better end-to-end reliability and diagnostics; unified remote explorer, capture-and-record options, user-controlled redundancy policies, exact duplicate inspector, conditional cloud-side jobs.

## Where they can beat us / reality check
Very high direct UX competitor; its multi-cloud right-click feature is not unique to REDOWN. Website pages disagree on rollout state: live landing page advertises three clouds; older terms/support say Google only; verify by testing.

## REDOWN API and cold-agent implications
Context-menu target model, routing/rule evaluation introspection, provider auth/scopes/folder diagnostics, replayable 403 traces, per-target transfer receipts.

## Concrete competitive / QA experiment
Reproduce user-observed Google Drive folder creation 403 in isolated authorized test account; classify insufficient scope vs provider error and show precise recovery; test Save All and auto-rules.

## Rules of engagement
Maintain REDOWN's one-click DONE workflow, user-owned execution model where authorized, no false transfer or replica success, no silent destructive cleanup, auditable provider scopes and error handling, accessible simple mode, desktop expansion via shared experience. Competitor strengths are inspiration; do not copy proprietary assets or obscure needed confirmation.
