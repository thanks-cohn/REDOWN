# REDOWN Competitive Intelligence — /COMP/

**Date:** 2026-10-23  
**Status:** Research-informed strategy; REDOWN features marked proposed are not verified as implemented.  
**Purpose:** Make each rival's strengths useful to REDOWN design, and provide a cold-start agent with the obligations, API questions and evidence needed to plan changes.  

## Non-negotiable strategic positioning
REDOWN sells **one-click DONE**: low-friction browser-first right-click remote saving, browser screenshot/recording, choose one cloud or many, dependable verified delivery, cross-cloud redundancy/duplicate awareness, later optional desktop application with shared UI, and customer-owned execution infrastructure where feasible. Never confuse ambitious targets with existing functionality. Do not compete with rclone only on feature-count, ShareX only on editing, or huge cloud firms on their distribution.

The UX standard: **small to install; easy to enter; beautiful to use; rigorous under failure.** Default shortcut bindings customizable/toggleable; notifications and sound OFF by default; success toolbar flash only after verified success, red on actual failure, fade to original; odometer counts verified results, no overshoot; clear partial outcomes.

## Core risk and critical corrections
- Google's own Save to Google Drive extension advertises screenshot-to-cloud; do NOT claim screenshot capture was invented by REDOWN.
- SaveAnywhere already advertises **Save to all connected**, auto-rules and a shelf, including Google Drive, Dropbox and OneDrive on its current home page. Some old official pages differ on launched providers; validate hands-on.
- rclone has an official local Web GUI.
- Cloud-side persistence requires a configured executable environment, permissions and potentially provider billing. Storage buckets alone do not run work. Customer-owned infrastructure may lower our costs but does not erase customer costs.
- A surviving provider's copy may restore a missing replica only after destination authorization returns; other providers' credentials do not grant it.
- Intentional replicas are **not** unwanted duplicates. Cleanup demands explicit review and independently verified survivor copies.

## Ranking principle
Score verified user journey, not aesthetic appeal or feature checkboxes: activation/first save time; task success; proportion of uploads independently verified; recoverability after interrupted browser, network, or revoked authorization; error diagnosis; accessibility; one/multi-cloud correctness; genuine provider costs; long-term maintenance. Take competitor ideas without copying protected visual assets or proprietary code.
