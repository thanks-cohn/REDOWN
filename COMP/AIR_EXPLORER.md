# Air Explorer — REDOWN competitor brief

**Category:** desktop multi-cloud file manager  
**Priority:** P1  
**Status:** Strategy with cited starting points; manually verify product versions and feature availability before implementing claims.

## What the competitor does well
Two-pane/cloud management, 50+ services, scheduled bidirectional sync, filtering, logs, encryption and parallel operations.

## What we should borrow as product principles
Dual-pane optional expert view, sync dry-runs, filters, conflict policies, comprehensive logs.

## Where REDOWN could win
Make tasks project-centric rather than two-filesystem-centric; lightweight browser shelf for daily actions, later familiar desktop app for huge local files.

## Where they can beat us / reality check
High for desktop users; do not promise lower CPU/memory without measurement.

## REDOWN API and cold-agent implications
Explorer list/tree/search, object metadata, upload/download/move, sync-plan preview, conflict resolution, local bridge.

## Concrete competitive / QA experiment
New user organizes and replicates a project with no explanation; audit destructive sync safe defaults.

## Rules of engagement
Maintain REDOWN's one-click DONE workflow, user-owned execution model where authorized, no false transfer or replica success, no silent destructive cleanup, auditable provider scopes and error handling, accessible simple mode, desktop expansion via shared experience. Competitor strengths are inspiration; do not copy proprietary assets or obscure needed confirmation.
