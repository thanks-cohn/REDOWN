## 4. GO TO IS NOT OAUTH (CRITICAL LESSON)

**GO TO** only navigates to a cloud provider website. Browser cookies may permit viewing the website while REDOWN Basic has **NO extension upload OAuth**. Do NOT infer save capability from GO TO or website login.

Keep states distinct:
- Not connected: no usable extension authorization.
- Connected: authenticated extension account/context exists.
- Authorized: upload scopes are available.
- Ready to Save: current token/scopes/required prerequisites support *attempting* upload (not guarantee).
- Saved: provider confirmed the intended item.

Cards need separate **Sign In**, **Reconnect/Approve**, **Refresh**, **GO TO** and readiness status as applicable. Refresh reuses valid tokens or silently renews when supported; never blindly force OAuth. Missing scopes require targeted reconnect, not 'GO TO'. If resume of pending save is insecure or risks duplicate upload, explicitly request retry. Every failure/recovery produces reason and next action. Test website GO TO working while upload OAuth is invalid for each provider.

## 6. BASIC HISTORY PAGE

Every meaningful save attempt gets its own record/card, including failed and uncertain outcomes:
- Filename, timestamp (local display), provider.
- Leading bullet: **GREEN success**, **RED failure**, **BLUE uncertain/unverified**; describe in-progress clearly and never fake completed.
- Independently expandable **image preview**, where available, otherwise compact fallback. Avoid broken preview images or needless full-object downloads.
- Below image, independent expandable heading **URLs**, with two separately labeled clickable, safe links when known:
  1. **Host page URL:** web page where right-click occurred.
  2. **Source resource URL:** direct file/image URL.
  Unknown means unavailable, not invented. Sanitize schemes/XSS; never upload these URLs as extra provider metadata.

Chronological organization: newest first; clear **days → weeks → years** sections. Define exclusive time boundaries and handle timezone/week/year rollover without duplicate/missing items.

**Pagination:** indexed, bounded records loading (e.g. IndexedDB), no full-history render. Default **40 per page**; configurable in Settings (e.g. 10,20,40,100). Next/previous/page indicator; responsive at thousands of records. **Lazy-load previews only when visible/needed**, with stable placeholders to prevent jumping rows; do not fetch every image on first paint.

Manual expand/collapse independently for image and URLs. Basic local History deletion/clear with confirmation; deletion must not delete cloud files or silently reset cumulative success count.

- Simple Clear Diagnostics action with confirmation; must not delete History/cloud files.

## 8. LIGHTWEIGHT DIAGNOSTICS, ZIP EXPORT

Place **Diagnostics** in **More ›**, not a heavyweight screen. Keep event list simple and paginated/limited if needed. Record only meaningful stages/outcomes: no per-byte events, no busy polling, no global forensic recorder.

Each applicable event should capture:
- Timestamp, attempt ID, provider, stage.
- **Success / Failure / Uncertain** and basic error code/short cause.
- **Host page URL** (where clicked), if known.
- **Source resource URL** (file/image URL), if known.
- **Transfer speed** only if measurably derived (bytes/time, clearly defined interval); else N/A. May also show bytes and duration for interpreting speed.
- Other minimal safe context, e.g. provider HTTP status/stage or redacted response code where useful.

Events should permit identifying why a given right-click failed without collecting file contents, access/refresh tokens, Authorization headers, session cookies, private response bodies or dangerous verbosity. URLs can contain private tokens/query strings: sanitize sensitive credentials where possible, retain inspectable safe values, store **locally**, and warn before export. Avoid sending diagnostic URL data to destinations/analytics/servers.

**Export Diagnostics ZIP** button: package *currently retained* events into a downloadable local ZIP (e.g. `events.jsonl`, `summary.json`, `README.txt`), including version, count, retention mode, export timestamp, error codes and recorded URLs/speed. No cloud upload. ZIP is available even when collection is switched OFF. Provide concise privacy warning that it may include browsing URLs. For very large/unlimited logs use bounded streaming/chunking where feasible; handle quota and export failures honestly. Prefer tiny established ZIP mechanism over heavy dependency.

Essential History/attempt records stay separate from optional diagnostics events: **turning diagnostics off cannot disable truthful saving or History**.
