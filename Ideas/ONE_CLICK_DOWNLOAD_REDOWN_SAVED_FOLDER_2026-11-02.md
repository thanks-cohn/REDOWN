# IDEA ONLY — Download the REDOWN Folder in One Click, with a Mascot Gang Yearbook Photo

**Date:** 2026-11-02  
**Status:** IDEA / NOT IMPLEMENTED / NOT PART OF ANY CURRENT CODEX REQUEST.  
**Branch:** `codex/v3-parity-first-reconstruction`

## Core idea

Give regular users and power users an optional **Download the REDOWN Folder** command. They can collect files over time in REDOWN-managed or REDOWN-selected cloud destinations and later **intentionally download their chosen collection to their own computer with one click**, ideally bundled as a normal ZIP with its original folder structure and trustworthy filenames/extensions.

This is **separate from REDOWN's TRUE REMOTE saving**. Standard right-click cloud saves continue without permanently downloading source files onto the user's PC; this button is a deliberate user-directed retrieval operation.

## Inside joke: include a special group photo in EVERY REDOWN-exported ZIP

Every ZIP generated by this eventual feature, whether exported from Cloudflare R2, Google Drive, Dropbox, OneDrive, another S3-compatible cloud, or an explicitly chosen future multicloud collection, should carry **one lightweight original image INSIDE THE ZIP** at its top level, **not uploaded to the remote provider**.

**Visual direction:** a charming, nostalgic **school yearbook / old friends group photo** of the REDOWN ecosystem mascot gang, with the **REDOWN logo** as an identifiable part of the image. AMEOBO (the glossy, playful chrome-rainbow shapeshifting REDOWN mascot) is posing with the other mascots, including future companion-app mascots such as **Framzy** where relevant, and a **new female mascot** whose name/design remain to be decided. The whole gang looks goofy and affectionate, like an old group photograph friends look back on years later: silly faces, tongues out, toothy grins, playful poses, one posing unexpectedly or making fun of the camera, and the new female mascot pulling a funny mouth/cheek expression. Nostalgic camaraderie, not a polished corporate marketing shot. No need to finalize her name or appearance now.

Art direction: warm, playful, a little awkward in a lovable way, tasteful retro photograph treatment (possibly subtle film grain, instant-camera frame, vintage yearbook caption, or a charming handwritten-note motif). Keep it **clearly an original REDOWN-owned image** with professionally drawn/created mascot art and branding. Avoid reusing copyrighted photographs, album art, or unrelated characters. It should be a tiny memorable easter egg that people discover by opening their downloaded files.

Suggested filename for planning: `HELLO-FROM-REDOWN.png`. Decide final filename, artwork, image resolution and compression during design review. Include exactly one bonus image per exported ZIP; don't confuse the image with a user's own file of the same name (reserve or rename the bonus entry safely). The bonus must not change file counts or checksums claimed for the user's original archive contents. The ZIP should otherwise contain only the selected, authorized files and necessary non-sensitive archive metadata. A user-controlled **include/exclude extras** setting can be considered later for professional/plain exports.

## Product and engineering constraints for future evaluation

- **Scope accurately:** The Cloudflare lowercase `redown` bucket is not automatically a folder. Other clouds may use an authorized root or selected target; **never create an unwanted REDOWN folder on Google Drive or other providers**, or silently export the whole provider root. Show exactly which provider, account, bucket/folder and contents are included before a huge export.
- **Per-provider first:** Start with a single explicitly selected collection. Future all-cloud ZIP could place each provider in its own labeled folder, with explicit confirmation and bounded API use.
- **One deliberate download, no cloud side effects:** No remote deletion, move, background sync, arbitrary upload of the bonus image, unrelated data sharing, or altered permissions.
- **Reliable ZIP:** Preserve hierarchy and extensions, handle duplicates and invalid local names, compute correct manifests/counts, paginate listings, stream within memory and Chrome MV3 limitations, give truthful progress, cancellation, failed-item reporting, and final archive verification. No false promise of unrestricted sizes or uninterrupted service-worker execution. If a provider cannot export a selected scope, show the limitation instead of inventing success.
- **Privacy:** Never add REDOWN page/source/frame/link URLs or browsing History provenance to cloud storage or embedded archive images. No third-party ZIP hosting by default. The surprise image is a packaged local bonus, not telemetry or watermark inserted into user files.
- **Accessibility and opt-in:** Normal browser download UX, standard ZIP format, obvious retrieval command and visible explanation that this *does* download to the PC.

## Future acceptance

Validate Cloudflare R2, Google Drive, Dropbox, OneDrive, and other available providers only when connected and genuinely authorized; empty folders, nested paths, large object sets, non-ASCII names, duplicate names, missing objects, cancellation, restart/uncertain download and remote data unchanged. Inspect the final ZIP: original selected files are intact, and exactly one **mascot gang + REDOWN logo image** is at the ZIP root, with no cloud-side upload of the bonus.

**Priority:** Product idea / P2 discovery after launch-blocking P0 saving fixes and main P1 Explorer/Shelf work. **Separate from the save-impact/SUCCESS! Codex handoff.**
