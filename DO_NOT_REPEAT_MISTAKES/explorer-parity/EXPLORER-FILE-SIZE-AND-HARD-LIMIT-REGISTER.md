# Explorer file-size and hard-limit register

Status: **AUDITED / implementation and installed acceptance open**. Updated 2026-10-28 (America/Chicago). Inspected `beta-explorer` at `a7effa80b20a4d12f9e6837486ff1d7f7e52ebd9`. Owner: REDOWN maintainer; subsequent operation authors maintain these references.

## Scope, evidence and units

This register distinguishes explicit code gates, operational defaults, implicit buffering and provider ceilings. **No universal Explorer file maximum exists.** Values are at the inspected revision. `>` means equality passes that gate, not that the provider completes the operation. MB = 1,000,000 B; MiB = 1,048,576 B. The UI's general KB/MB/GB formatter uses binary divisors with decimal-looking labels; never use it to infer protocol boundaries.

Source shorthand: **A** [r2-adapter.mjs](../../extension/beta/r2-adapter.mjs); **U** [file-api.mjs](../../extension/beta/file-api.mjs); **O** [configuration.mjs](../../extension/beta/configuration.mjs); **L** [options.js](../../extension/options.js); **G** [background.js](../../extension/background.js) (embedded Worker and extension handlers); **C** [cloudflare-api.js](../../extension/cloudflare-api.js); **S** [search-session.js](../../extension/search-session.js). Anchor line numbers are snapshot-specific; symbols are authoritative. [Search evidence](evidence/source-limit-candidates.txt) retains additional numeric/buffer candidates and [hashes](evidence/source-baseline.json) bind the inspection. Layout dimensions, timestamps, formatting, OAuth IDs, source-map/diagnostic export caps and library internals are not file payload limits. Relevant telemetry caps are separately noted below; frozen historical engines and vendored renderers are not integrated transfer routes.

All enforcement behavior below is CODE-INFERRED except explicitly VERIFIED local boundary probes / focused tests. Provider documentation is retrieved evidence of published constraints, not proof of deployed account settings. Installed/browser/live cloud limits remain UNVERIFIED.

R2 storage per bucket/object count may be documented unlimited, but project paging, RAM, request quotas and UI are finite. Binary previews/media decode, PDF renderer, model-viewer dependencies and browser Blob implementations introduce type/device-specific limits not represented by F01. A successful small fixture cannot establish a numerical device ceiling.
