## Five highest-priority recommended repairs

1. **P0: make existing cloud operations' duration/results truthful before raising size claims.** `background.js:callBucketWorker` (1566) still cuts off at 30s; cross-Worker GET (133) at 25s despite configurable Beta outer deadlines in `configuration.mjs`/`r2-adapter.mjs:message`. Plumb a bounded deadline through the *existing* route, preserve ambiguous-write non-replay, and characterize delayed receipts. Separately verify requested archive counts vs receipts (`background.js:537/553` silently slices 1000). This protects current parity at large file/count boundaries; it does not add a new engine or claim infinite duration.
2. **P1: restore local-upload availability without automatic deployment.** Legacy `options.js:uploadLocalFiles` (1405) can PUT to authorized buckets without a ready Worker; Beta `explorer.mjs:upload/run/ensureWorker` (150/95/101) and adapter final staged commit (171–199) require one. Expose this concrete prerequisite accurately and select the smallest explicit-setup or existing-direct-route integration that meets conflict/integrity semantics. If using a compatibility direct route, preserve Legacy Skip-only restriction and truthful verification instead of claiming staged Replace guarantees. Do not silently provision or drop staging integrity. Characterize the no-profile case first; merely removing ensureWorker still fails at final move.
3. **P1: scoped remote search.** Wrap existing `background.js` `cfSearchStart/Step/Cancel` and `search-session.js` through `file-api.mjs`/R2 adapter; add Beta result source identity and containing-folder navigation (`options.js:runExplorerSearch` 2085 is reference). Preserve search budgets, interrupted/partial state and current pagination. No new index or scan engine. Retain loaded-name filter as a distinct operation.
4. **P1: complete archive parity with existing routes.** Add adapter/API entry reads/download and archive transfer over `cfArchiveEntryUrl` (G2585 vicinity), `cfTransferArchive` (G2591), `receiveArchiveEntries` (G550). Then adapt Legacy archive-folder/clipboard mapping (L3011–3110) to Beta dialog. Preserve no-provisioning, signed URLs, count validation and safe expansion limits. Fix shared output-buffer protection before certifying large entries; no second ZIP parser.
5. **P1: restore preview type/read coverage.** Share metadata-aware MIME resolution (`options.js:objectContentType` 1531), existing 403 managed-public fallback (`cloudflare-api.js:readableResponse` 116) and bundled model-viewer (L1675) behind the universal API. Keep Beta configurable read budget and true text truncation. Tests must show Legacy/Beta same MIME/key can preview; missing codecs/private public-access states are explicit, not fake success.

## Release gates and acceptance ownership

Track repaired matrix IDs in the same commit as code/tests. Retain provider constraints (key length, multipart protocol, quotas), resource-safety limits and precise route-specific labels. The 16 MiB Test It check is not a normal Explorer cap to remove. The 300 MB local gate is shared Legacy/Beta debt whose exact endpoint justification needs fresh proof; do not remove it and call an invalid same-endpoint request a repair. Known-length TRUE REMOTE, cloud copy and Chrome download already bypass that *local upload* gate within their own limits.

No automatic cloud setup, new credential flow, framework, provider or broad refactor is necessary for phases 1c–1g.
